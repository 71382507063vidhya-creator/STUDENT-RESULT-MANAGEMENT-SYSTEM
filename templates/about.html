About This Project

The Student Result Management System is a college-level full-stack project built with Flask, SQLite and Bootstrap. It lets administrators manage students, subjects and marks, automatically calculates results (total, average, grade, and pass/fail), and celebrates passing students with an animated 🍫 Chocolate Shower.

All result calculations - including the PASS/FAIL decision - happen on the backend, so the outcome shown to a student can never be manipulated from the browser.

The project ships with automated pytest tests and a GitHub Actions continuous integration workflow that runs on every push and pull request.
